# Brazil Tomato Production Analysis 

## Project Overview

This project analyzes tomato production in Brazil from 2014 to 2023 using public data from IBGE SIDRA.

The goal was to explore production trends, harvested area, regional production, and tomato yield while developing practical data analysis and data visualization skills in Excel.

## Tools

- Microsoft Excel
- Pivot tables and data organization
- Charts and data visualization
- Descriptive analysis

## Dataset

**Source:** IBGE – SIDRA  
**Survey:** Municipal Agricultural Production (PAM)  
**Period:** 2014–2023

The analysis includes data on:
- Tomato production
- Harvested area
- Yield
- Production by Brazilian state

## Key Insights

- Tomato production decreased by 3.18% between 2014 and 2023.
- Production reached its lowest level in 2021.
- Production increased by 9.90% in 2023, indicating a strong recovery.
- Tomato harvested area decreased by approximately 8.3% between 2014 and 2023.
- Goiás was the leading tomato-producing state in 2023.
- Goiás also recorded the highest yield among states with available yield data in 2023.

## Dashboard

The Excel dashboard summarizes the main production indicators and visualizes:

- Tomato production trends from 2014–2023
- Annual production changes
- Harvested area trends
- Yield differences among the leading states
